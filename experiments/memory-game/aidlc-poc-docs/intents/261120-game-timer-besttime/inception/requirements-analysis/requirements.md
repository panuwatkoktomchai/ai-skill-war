# ความต้องการ: จับเวลาและสถิติเวลาดีที่สุด

## Sources

- [desc] Initial description: เพิ่มจับเวลาตั้งแต่เริ่มจนชนะ และจำสถิติดีที่สุด (เวลาน้อยสุด) ไว้ในเครื่อง แสดงบนหน้าเกม
- [scope] Workflow-selected scope: express
- โค้ดปัจจุบัน: `src/App.tsx` (component `App`, เฟส `preview` / `playing` / `won`), `src/style.css`

## Intent analysis

ผู้เล่นต้องการรู้ว่าชนะเกมจับคู่การ์ดได้เร็วแค่ไหน และอยากเห็นสถิติที่ดีที่สุดของตัวเองค้างอยู่ แม้จะปิดเบราว์เซอร์แล้วเปิดใหม่ งานนี้เป็นการเพิ่มฟีเจอร์เล็กใน component เดียว ไม่มีเซิร์ฟเวอร์และไม่มีบัญชีผู้ใช้

## Functional requirements

- **FR1 จับเวลา**
  - **FR1.1** ระบบต้องเริ่มนับเวลาเมื่อเฟสเปลี่ยนจาก `preview` เป็น `playing` (หลังการ์ดคว่ำ) โดยไม่นับช่วง 3 วินาทีที่เปิดให้ดู [assumption]
  - **FR1.2** ระหว่างเล่น ระบบต้องแสดงเวลาที่ผ่านไปบนหน้าเกม อัปเดตอย่างน้อยทุก 1 วินาที ในรูปแบบ `นาที:วินาที` (เช่น `00:07`)
  - **FR1.3** ระบบต้องหยุดนับทันทีที่จับคู่ครบทุกคู่ (เฟส `won`) และคงเวลานั้นไว้บนหน้าจอ
  - **FR1.4** เมื่อกด "เล่นใหม่" ระบบต้องรีเซ็ตเวลาเป็น `00:00` และเริ่มนับใหม่เมื่อเข้าเฟส `playing` ของรอบใหม่
- **FR2 สถิติดีที่สุด**
  - **FR2.1** เมื่อชนะ ระบบต้องเทียบเวลาที่ใช้กับสถิติที่เก็บไว้ ถ้ายังไม่มีสถิติ หรือเวลาใหม่น้อยกว่า ให้บันทึกเวลาใหม่เป็นสถิติดีที่สุด
  - **FR2.2** ถ้าเวลาใหม่เท่ากับหรือมากกว่าสถิติเดิม ระบบต้องไม่เปลี่ยนสถิติ
  - **FR2.3** ระบบต้องเก็บสถิติไว้ในเบราว์เซอร์ของผู้เล่น (`localStorage`) ให้ยังอยู่หลังรีเฟรชหรือปิดแล้วเปิดใหม่
- **FR3 การแสดงผล (ภาษาไทย)**
  - **FR3.1** หน้าเกมต้องแสดงสถิติดีที่สุดตลอดเวลา เป็น `สถิติดีที่สุด: นาที:วินาที` หรือ `สถิติดีที่สุด: -` เมื่อยังไม่มีสถิติ
  - **FR3.2** ข้อความชนะต้องแสดงเวลาที่ใช้ และแจ้ง "สถิติใหม่!" เมื่อทำลายสถิติ รวมถึงการชนะครั้งแรกที่ยังไม่มีสถิติเดิม
- **FR4 การเก็บข้อมูลเมื่อมีปัญหา**
  - **FR4.1** ถ้าอ่านหรือเขียน `localStorage` ไม่ได้ (เช่น private mode หรือพื้นที่เต็ม) เกมต้องเล่นต่อได้ตามปกติโดยไม่แสดง error และสถิติจะใช้ได้เฉพาะในหน้านั้น
  - **FR4.2** ถ้าค่าที่เก็บไว้ไม่ใช่ตัวเลขจำนวนเต็มที่มากกว่า 0 ระบบต้องถือว่ายังไม่มีสถิติ

## Non-functional requirements

- **NFR1 ความถูกต้องของเวลา**: เวลาที่แสดงตอนชนะต้องคลาดเคลื่อนจากเวลาจริงไม่เกิน 1 วินาที คำนวณจากนาฬิการะบบ (`Date.now()`) ไม่ใช่จากการนับจำนวนรอบของ interval
- **NFR2 ไม่มี timer ค้าง**: ตัวจับเวลาต้องถูกล้างเมื่อ component ถูก unmount หรือเกมจบ และต้องไม่มี interval ซ้อนกัน แม้ `StrictMode` จะรัน effect สองครั้งตอนพัฒนา
- **NFR3 ไม่กระทบเกมเดิม**: กติกาเดิมทำงานเหมือนเดิมทุกข้อ ได้แก่ เปิดดู 3 วินาที, เปิดทีละ 2 ใบ, คว่ำกลับหลัง 1 วินาที, นับจำนวนครั้ง และปุ่มเล่นใหม่
- **NFR4 การ build**: `npm run build` (รวม `tsc`) ต้องผ่านโดยไม่มี error และไม่เพิ่ม dependency ใหม่

## Constraints

- ใช้ React + TypeScript + Vite เดิม ไม่เพิ่มไลบรารี
- เก็บข้อมูลฝั่งเบราว์เซอร์เท่านั้น ไม่มี backend
- ข้อความบนหน้าเกมเป็นภาษาไทย

## Assumptions

- [assumption] เริ่มนับเวลาหลังช่วงเปิดการ์ดให้ดู 3 วินาที เพราะ "เริ่มเล่น" คือตอนที่ผู้เล่นเริ่มคลิกได้ และช่วงดูการ์ดยาวเท่ากันทุกรอบ ไม่ได้วัดฝีมือผู้เล่น
- [assumption] เก็บสถิติเดียวต่อเบราว์เซอร์ ไม่แยกตามผู้เล่น เพราะเกมมีด่านเดียว
- [assumption] สถิติดีที่สุดวัดจากเวลาอย่างเดียว ไม่นำจำนวนครั้งที่เปิดมาร่วมตัดสิน ตามที่ระบุว่า "เวลาน้อยสุด"
- [assumption] แสดงผลระดับวินาที ซึ่งละเอียดพอสำหรับเกมนี้
- [assumption] ไม่มีปุ่มล้างสถิติ เพราะไม่ได้ขอไว้

## Out of scope

- ตารางอันดับหลายรายการ หรือสถิติแยกตามผู้เล่น
- ปุ่มล้างสถิติ
- ซิงก์สถิติข้ามเครื่อง
- เปลี่ยนกติกาหรือหน้าตาเกมส่วนอื่น
- จับเวลาถอยหลังหรือจำกัดเวลา
