# Business Overview

## Purpose
เกมจับคู่การ์ด (memory card) ภาษาไทยที่เล่นในเบราว์เซอร์ ผู้เล่นดูการ์ดอิโมจิ 3 วินาที แล้วคว่ำการ์ด และเปิดทีละคู่จนจับคู่ครบ 6 คู่ (12 ใบ). ชื่อใน `index.html`: "เกมจับคู่การ์ด"; `README.md` มีเพียง `# ai-skill-war`.

## Key Functionality
- ช่วง preview: โชว์การ์ดทั้งหมด 3 วินาที (`PREVIEW_MS`)
- ช่วง playing: เปิดสองใบ ถ้าตรงกันค้างไว้ ไม่ตรงคว่ำกลับหลัง 1 วินาที (`MISMATCH_MS`)
- นับจำนวนครั้งที่เปิด (`moves`)
- ช่วง won: แสดงข้อความยินดีพร้อมจำนวนครั้ง และปุ่ม "เล่นใหม่"

## Current Gaps (เกี่ยวกับ intent game-timer-besttime)
ไม่มีตัวจับเวลา และไม่มีการเก็บข้อมูลข้ามการโหลดหน้า จึงยังไม่มีเวลาที่ดีที่สุด. รายละเอียดโค้ดดู `architecture.md`.

## Users
ผู้เล่นคนเดียวบนเบราว์เซอร์ ไม่มีบัญชีผู้ใช้หรือ backend.
