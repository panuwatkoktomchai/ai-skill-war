# Spike S2: ผู้ช่วย AI รับสายแทนผู้สูงอายุ (Gemini Live)

หน้าเว็บสำหรับทดลองคุยกับ AI ที่รับสายแทน "คุณแดง" ผ่านไมค์ เพื่อเช็ก 3 อย่างก่อนต่อเข้ากับสายโทรจริง (Twilio):

1. Gemini Live ฟังภาษาไทยถูกไหม โดยเฉพาะเมื่อเสียงเป็นคุณภาพสายโทรศัพท์ 8 kHz
2. ตอบช้าแค่ไหน หน้าเว็บแสดงเวลาตั้งแต่ผู้โทรหยุดพูดจนถึง AI เริ่มพูด
3. AI จับมิจฉาชีพได้ไหม AI จะเรียก function `report_call` ตอนจบสาย แล้วหน้าเว็บแสดงผลเป็นการ์ดแบบข้อความ LINE

แผนทั้งหมดอยู่ที่ `docs/ideas/ai-call-screening.md` (repo apgame29/ai-skill-war ซึ่งจะย้ายมาไว้ที่นี่ทีหลัง)

## วิธีรัน

```bash
cd experiments/voice-agent
npm install
cp .env.example .env    # แล้ววาง GEMINI_API_KEY ลงใน .env (ไฟล์นี้ไม่ขึ้น git)
npm start               # เปิด http://localhost:5180 ด้วย Chrome
```

ใส่หูฟังตอนทดสอบ ไม่งั้นเสียง AI จะย้อนเข้าไมค์

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `server.mjs` | เสิร์ฟหน้าเว็บ และออก ephemeral token (ใช้ครั้งเดียว อายุ 30 นาที) ให้เบราว์เซอร์ · API key จริงอยู่แค่ฝั่งเซิร์ฟเวอร์ |
| `public/agent-config.js` | **prompt + function `report_call` + บทให้คนทดสอบอ่าน** · ถ้าจะจูน AI ให้แก้ไฟล์นี้ |
| `public/app.js` | ต่อ Gemini Live, จัดการข้อความถอดเสียง, แสดงการ์ดผล |
| `public/audio.js` | อัดไมค์ → PCM16 (16 kHz หรือ 8 kHz) · เล่นเสียง PCM16 24 kHz · หยุดเสียงเมื่อผู้โทรพูดแทรก |

- model ตั้งต้นคือ `gemini-3.8-live` · เปลี่ยนได้ด้วย `GEMINI_LIVE_MODEL` ใน `.env`
- SDK `@google/genai` 3.6.1 · ฝั่งเบราว์เซอร์โหลดจาก esm.sh (pin version ไว้ใน `index.html`)
