# ระบบให้คะแนนมิจฉาชีพ (สรุปให้จำไปทำใหม่ใน Kiro วันแข่ง)

โค้ดจริงอยู่ที่ `public/risk.js` · ชุดทดสอบอยู่ที่ `eval/` · ไฟล์นี้คือสิ่งที่ต้องจำ

## หลักการ 1 ประโยค

> **AI ทำหน้าที่ "จับสัญญาณ" ส่วนโค้ดทำหน้าที่ "คิดคะแนนและตัดสินใจ"**

- AI ฟังผู้โทรแล้วติ๊กว่าเจอสัญญาณข้อไหน พร้อมยกคำพูดของผู้โทรเป็นหลักฐาน ไม่ต้องตัดสินเอง
- โค้ดบวกน้ำหนักของสัญญาณที่เจอ แล้วตัดสินว่าจะโอนสายให้ยายหรือจบสายแล้วแจ้ง LINE
- **ทำไมแยกแบบนี้:**
  1. **อธิบายกรรมการได้ทุกคะแนน** ว่ามาจากสัญญาณไหนและคำพูดไหน
  2. **มิจฉาชีพหลอก AI ให้โอนสายไม่ได้** เพราะ AI ไม่ได้เป็นคนตัดสิน
  3. **ปรับน้ำหนักได้เองจากผลชุดทดสอบ** ไม่ต้องแก้ prompt

## สัญญาณ 11 ตัว + 1 ตัวจากระบบ

| สัญญาณ | น้ำหนัก | ห้ามโอนเด็ดขาด | ตัวอย่างคำพูด |
|---|---|---|---|
| ขอให้โอนเงิน / จ่ายค่าธรรมเนียม | **+40** | ✅ | "โอนเงินมาตรวจสอบ" "ค่าธรรมเนียมเปิดวงเงิน" |
| ขอ OTP / รหัส / เลขบัตร / เลขบัญชี | **+35** | ✅ | "แจ้งเลข OTP" "ขอเลขบัญชีเพื่อโอนเงินคืน" |
| อ้างเป็นเจ้าหน้าที่ + บอกว่ามีคดี / บัญชีมีปัญหา | **+30** | | "บัญชีถูกใช้ฟอกเงิน" "พัสดุมียาเสพติด" |
| ให้ติดตั้งแอป / กดลิงก์ / แอดไลน์ | **+30** | ✅ | "แอดไลน์เจ้าหน้าที่" "ลงแอปตามลิงก์" |
| อ้างเป็นลูกหลานแต่ใช้เบอร์แปลก | **+30** | | "แม่ ผมเปลี่ยนเบอร์ใหม่" |
| ข้อเสนอดีเกินจริง (ลงทุน งาน เงินคืน สิทธิ) | **+25** | | "ผลตอบแทนเดือนละ 20%" |
| เร่ง / ข่มขู่ / ห้ามบอกคนอื่น | **+20** | | "ภายในวันนี้" "ห้ามบอกลูกหลาน" |
| ไม่บอกตัวตน หรือข้อมูลขัดกันเอง | **+15** | | ไม่บอกชื่อ ไม่ให้เบอร์กลับ |
| **(จากระบบ)** เบอร์ขึ้นต้น +697 / +698 = โทรจากต่างประเทศ | **+20** | | ได้มาจากแอปบนมือถือ ไม่ได้มาจาก AI |
| บอกชื่อ หน่วยงาน และเบอร์กลับครบ | **−15** | | "พยาบาลสมใจ ศบส.23 โทรกลับเบอร์นี้" |
| ธุระทั่วไป ไม่เกี่ยวกับเงินหรือข้อมูลลับ | **−15** | | นัดหมาย ส่งของ แจ้งข่าว |
| ให้ไปติดต่อผ่านช่องทางทางการเอง | **−10** | | "มายืนยันสิทธิ์ที่สำนักงานเขต" |

**วิธีตัดสิน:**
- คะแนน = ผลบวกน้ำหนักทั้งหมด แล้วตัดให้อยู่ในช่วง 0–100
- **60 ขึ้นไป = มิจฉาชีพ** → จบสาย ส่ง LINE เตือน
- **30–59 = น่าสงสัย** → จบสาย ส่ง LINE ให้โทรกลับเบอร์ทางการเอง
- **ต่ำกว่า 30 = สายจริง** → โอนสายให้ยาย
- **กฎเหล็ก:** ถ้าเจอ "ขอเงิน" "ขอข้อมูลลับ" หรือ "ให้ย้ายช่องทาง" **ห้ามโอนสายเด็ดขาด** ต่อให้คะแนนรวมต่ำ

น้ำหนักทั้งหมดเป็นค่าตั้งต้นที่ทีมกำหนดเอง แล้วจูนด้วยชุดทดสอบ **ไม่ได้มาจากงานวิจัย** ถ้ากรรมการถาม ให้ตอบตามนี้ตรงๆ

## ทำไมสัญญาณพวกนี้

ตำรวจไซเบอร์ระบุ 4 มุกที่ทำให้ผู้สูงอายุเสียเงินมากที่สุดในปี 2569 คือ หลอกลงทุน · โทรขู่อ้างเป็นเจ้าหน้าที่ · งานเสริม · หลอกให้โอนเพื่อรับสิทธิหรือเงินคืน ทุกมุกต้องจบที่ **"ให้โอนเงิน" หรือ "ให้ข้อมูล"** สัญญาณ 2 ตัวนี้จึงมีน้ำหนักสูงสุด และตั้งเป็นกฎห้ามโอนสาย

อีกข้อที่ต้องจำ: **หน่วยงานรัฐและธนาคารจริงไม่ขอให้โอนเงินหรือขอ OTP ทางโทรศัพท์**

## ข้อความ LINE (โค้ดเป็นคนสร้าง AI ไม่ได้เขียนเอง)

- มิจฉาชีพ: `⚠️ สายมิจฉาชีพ: {ใคร} {ธุระ} · ห้ามโอนเงิน ห้ามให้ข้อมูล และไม่ต้องโทรกลับนะคะ`
- น่าสงสัย: `❓ สายน่าสงสัย: {ใคร} {ธุระ} · ถ้าจะโทรกลับ ให้โทรเบอร์ทางการของหน่วยงานนั้นเอง`
- สายจริง: `✅ โอนสายให้แล้ว: {ใคร} {ธุระ}`

## ผลชุดทดสอบ

รอบแรก (22 พ.ย. 2569 · gemini-3.8-live · ส่งบทเป็นข้อความ ไม่ใช่เสียง): **ถูก 20/20 · มิจฉาชีพหลุดถึงยาย 0/12 · สายจริงโดนกัน 0/8** (ดู `eval/results.md` · รันซ้ำด้วย `npm run eval`)

**อย่าเพิ่งเชื่อ 100%:**
- ชุดนี้ทีมเขียนเอง และบทมิจฉาชีพส่วนใหญ่โจ่งแจ้ง
- รันแค่รอบเดียว
- ยังไม่ได้ลองผ่านเสียงครบทุกบท

**ต้องเพิ่มบทยากก่อนเอาตัวเลขไปพิตช์:**
- มิจฉาชีพที่ยังไม่ขอเงินในสายแรก
- สายจริงที่พูดถึงเงิน เช่น ร้านยาแจ้งค่ายา
- ธนาคารจริงโทรแจ้งเตือนธุรกรรม
