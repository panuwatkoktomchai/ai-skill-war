## 0. หลักการออกแบบ (ผู้สูงอายุเป็นศูนย์กลาง)

1. **AI เป็นฝ่ายเริ่มก่อน:** ผู้สูงอายุไม่ต้องจำว่าต้องเปิดแอป · ทุกบริการในไทยตอนนี้รอให้ผู้ใช้เริ่มเอง (ช่องว่างข้อ 1)
2. **พูดได้ ไม่ต้องอ่าน:** ใช้เสียงภาษาไทยเป็นหลัก ปุ่มใหญ่เป็นทางสำรอง
3. **ไม่ต้องเปลี่ยนพฤติกรรม:** ดูสัญญาณจากการใช้มือถือตามปกติ ไม่ต้องใส่นาฬิกาหรือติดกล้อง (แนวคิดเดียวกับกาต้มน้ำ Zojirushi)
4. **ผู้สูงอายุเป็นคนเลือกว่าจะแชร์อะไรให้ใครรู้:** ไม่ใช่ระบบให้ลูกหลานเฝ้าดู · สรุปที่ส่งให้ญาติเป็นข้อความสั้น ไม่ส่งเสียงหรือคำพูดดิบ
5. **มีคนรับเรื่องต่อเสมอ แม้ไม่มีลูกหลาน:** ลำดับคือ ญาติ → เพื่อนบ้าน / อสส. / ศบส. → 1669 (ช่องว่างข้อ 2, 4)

## 3. รวมเป็นตัวเดียว: เสนอชื่อชั่วคราว "หลานAI"

> **"เพื่อน AI ที่ทักก่อนทุกวัน และมีคนรับเรื่องต่อเสมอ แม้ไม่มีลูกหลาน"**

- **แกน (ต้องรันได้ในวันแข่ง):**
  - I1 AI ทักก่อนทุกเช้า + I2 ส่งเรื่องต่อเป็นขั้น
  - ข้อมูลที่ใช้ตัดสินใจ: I4 ความปกติจากกิจวัตร + I7 ภัยเมือง
- **ตัวสร้างความว้าวอันที่ 2 (เลือก 1 อย่าง):**
  - **I3 กันมิจฉาชีพ** มีตัวเลขแรงที่สุด และ demo บนเวทีได้ง่าย แนะนำตัวนี้
  - หรือ I6 ถ่ายรูปซองยา ทำง่ายที่สุด
- **ใส่ไว้ใน roadmap:** I5 ล้ม · I8 สิทธิ · I9 ความจำ · I10 ชุมชน · I11 สรุปให้ลูกหลาน · I12 แผนที่ กทม.

### ทำไมรวมแบบนี้

- **ตรงช่องว่างที่ใหญ่ที่สุดในไทย:** ช่องว่างข้อ 1+2+3+4+12 ในไฟล์ competitors และมีต้นแบบจริงอย่าง CareCall ที่เกาหลีใช้ 128 เขตให้อ้างอิง กรรมการถามว่า "มีคนทำหรือยัง" ตอบได้ทันที
- **AI ทำงานเป็น agent จริง:** ฟังและคุย → ประเมินความเสี่ยงจากหลายสัญญาณ → ตัดสินใจเรียก tool (แจ้งญาติ / อสส. / 1669) เหมาะกับเกณฑ์ AI Integration Depth 25
- **ผูกกับกรุงเทพจริง:** ใช้ air4thai และดัชนีความร้อน · ส่งต่อให้ ศบส. ที่มี 69 แห่ง และ อสส. · มีแผนที่ให้ กทม. · และพิตช์ได้ว่า "กทม. มีผู้สูงอายุ 1.27 ล้านคน แต่ไม่มีตัวเลขว่าใครอยู่คนเดียว"

### flow ที่จะ demo บนเวที (ราว 3 นาที)

1. ตั้งค่าเป็นวันที่ฝุ่นสีส้ม ร้อน 44°C → หลานAI ทักยายแดงด้วยเสียงไทย "วันนี้ร้อนมากนะคะ ยายกินยาความดันหรือยังคะ"
2. ยายตอบ "กินแล้ว แต่เวียนหัวนิดหน่อย" → AI ถามต่อ แล้วประเมินว่า **น่าห่วง**
3. → LINE ลูกสาวเด้งบนจอ: สรุปอาการ + ปุ่มโทรหาแม่
4. มีสายจาก "เจ้าหน้าที่ตำรวจ" เบอร์แปลกโทรเข้า → แอปเตือนก่อนรับ → หลังวางสาย AI ถามว่า "เขาให้ยายโอนเงินไหมคะ" → ยายตอบว่าใช่ → AI บอกยายว่าอย่าโอน และแจ้งลูกสาวทันที
5. จำลองว่ายายเงียบหายไป 6 ชม. ผิดจากกิจวัตร และโทรแล้วไม่รับ → ส่งเรื่องให้ อสส. หรือ ศบส. ในเขต → เปิดหน้าโทร 1669 พร้อมข้อมูลโรคประจำตัว
6. ปิดด้วยแผนที่ กทม.: วันนี้มีผู้ใช้ที่เสี่ยงในแต่ละเขตกี่คน

### ความเสี่ยงที่ต้องคิดก่อน

| ความเสี่ยง | ทางแก้ |
|---|---|
| Gemini Live ฟังเสียงไทยพลาดเพราะในฮอลล์เสียงดัง | ใช้ไมค์ติดตัว + มีช่องพิมพ์สำรอง + วิดีโอสำรอง |
| ยังไม่รู้ว่าเปิดวิดีโอสำรองแล้วโดนหักคะแนน "ทำงานได้จริง" ไหม | ถามผู้จัด |
| ข้อมูลสุขภาพเป็นข้อมูลอ่อนไหวตาม PDPA | ขอความยินยอมทีละเรื่อง · เก็บน้อยที่สุด · ส่งญาติแค่สรุป |

| ทำครบทุกอย่างไม่ทันใน 1 วัน | ล็อกแกนไว้ที่ I1 + I2 + I4 + I7 แล้วเพิ่มได้แค่ 1 ตัวว้าว |

## 4. คำถามที่ยังเปิดอยู่ (ทีมตัดสิน)

4. ฝั่ง อสส. / ศบส. ใน demo จะใช้ LINE group จำลอง หรือทำ dashboard เล็กๆ
