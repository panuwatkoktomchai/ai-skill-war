# หลานAI: บันทึกทั้งหมด + คู่มือสร้างใหม่วันแข่ง

อัปเดต 23 พ.ย. 2569 · เขียนให้ Game อ่านบนมือถือวันแข่ง (30 พ.ย.) แล้วสั่ง Kiro (Opus 5.5) สร้างใหม่ตามได้

**อ่านตามลำดับนี้:**
1. สรุป 1 หน้า (ข้อ 1)
2. สิ่งที่คุยและตัดสินใจไปแล้ว (ข้อ 2) ไว้ตอบกรรมการว่าทำไมทำแบบนี้
3. สั่ง Kiro ทีละขั้น (ข้อ 5) ก๊อปไปวางได้เลย

โค้ดต้นแบบที่ลองแล้วว่าใช้ได้อยู่ที่ `experiments/voice-agent/` (branch `apgame/spike-voice-agent`)

## 1. สรุป 1 หน้า

**ปัญหา:**
- ผู้สูงอายุอายุ 60+ แจ้งความแค่ **8%** ของคดีออนไลน์ แต่เสียเงินไป **28.55%** ของความเสียหายทั้งหมด (3,152 ล้านบาท ใน 8 เดือนแรกของปี 2569 · ตำรวจไซเบอร์)
- ในไทยยังไม่มี AI ภาษาไทยที่รับสายแทนผู้สูงอายุ ที่มีอยู่ก็แค่ดูเบอร์อย่างเดียว

**สิ่งที่ทำ:** แอป Android "หลานAI" ลงในมือถือยาย

**journey (Game เคาะ 22 พ.ย.):**
```
มีสายเข้า
├─ เบอร์ที่บันทึกไว้ → ดังตามปกติ ยายรับเอง
└─ เบอร์แปลก → แอปปฏิเสธสาย → ค่ายมือถือโอนไปเบอร์ AI (ตั้ง **67* ไว้ครั้งเดียว)
     AI รับแทน: "สวัสดีค่ะ บ้านคุณแดงค่ะ ดิฉันเป็นผู้ช่วยของคุณแดง..."
     AI จับสัญญาณ → โค้ดคิดคะแนน
     ├─ สายจริง → "รอสักครู่นะคะ ดิฉันจะโอนสายให้คุณแดงค่ะ" → โทรเข้ามือถือยาย + แอปเด้งบอกก่อนว่าใครโทรมา
     ├─ น่าสงสัย / มิจฉาชีพ → AI ลาสุภาพ ไม่โอน → LINE เตือนยายและลูกหลาน
     └─ เงียบเกิน 8 วินาที → AI ลาแล้ววาง ไม่แจ้ง LINE ทันที (เก็บไว้สรุปรายวัน)
```

**เทคโนโลยี:**
- Gemini Live (`gemini-3.8-live`) คุยเสียงภาษาไทย
- Function calling `report_call`
- โค้ดคิดคะแนนเอง (`risk.js`)
- LINE Messaging API
- Twilio (เบอร์ AI) + Android CallScreeningService

**สิ่งที่พิสูจน์แล้ว (22 พ.ย.):**
- AI ฟังไทยจากเสียงคุณภาพสายโทรศัพท์ 8 kHz ได้แม่น
- ตอบหลังผู้โทรหยุดพูด 1.3–1.6 วินาที
- ชุดทดสอบ 20 บทถูก 20/20 (บทที่ทีมเขียนเอง ส่งเป็นข้อความ รันรอบเดียว)

## 5. สั่ง Kiro ทีละขั้น (ก๊อปไปวาง)

ทำทีละขั้น ลองให้รันได้ก่อนแล้วค่อยไปขั้นถัดไป

### ขั้น 1: เว็บทดลองคุยเสียงกับ Gemini Live

```
สร้างเว็บแอปเล็กๆ (Node.js ไม่ใช้ framework) สำหรับทดลอง AI รับสายแทนผู้สูงอายุ
- server.mjs: เสิร์ฟไฟล์ใน public/ และมี POST /api/session ที่ใช้ @google/genai
  สร้าง ephemeral token (ai.authTokens.create, uses 1, หมดอายุ 30 นาที,
  apiVersion v1beta) จาก GEMINI_API_KEY ใน .env · key จริงต้องไม่ส่งไปเบราว์เซอร์
  · bind แค่ 127.0.0.1
- เบราว์เซอร์ใช้ token ต่อ ai.live.connect model gemini-3.8-live
  responseModalities AUDIO, inputAudioTranscription, outputAudioTranscription
- อัดไมค์ด้วย AudioWorklet → แปลงเป็น PCM16 → ลด sample rate เป็น 8000 (จำลองสายโทรศัพท์)
  ส่งทุก 40ms ด้วย sendRealtimeInput mimeType audio/pcm;rate=8000
- เล่นเสียงที่ได้กลับ (PCM16 24kHz) ต่อคิวกัน หยุดทันทีเมื่อได้ serverContent.interrupted
- realtimeInputConfig.automaticActivityDetection: start/end sensitivity HIGH,
  prefixPaddingMs 100, silenceDurationMs 500
- ประกาศตัวแปร session ด้วย let ก่อน await connect (onmessage ยิงมาก่อน connect resolve)
- หลังต่อสาย ส่ง sendClientContent "(มีสายเข้า ผู้โทรรออยู่)" ให้ AI ทักก่อน
- หน้าจอ: ปุ่มรับสาย/วางสาย, ช่องเบอร์ที่โทรเข้า (จำลอง), บทสนทนา, เวลาตอบ
```

## 6. prompt ตัวจริงของผู้ช่วย (ก๊อปไปวาง)

```
คุณคือ "ผู้ช่วยหลานAI" ทำหน้าที่รับสายโทรศัพท์แทนคุณแดง ผู้สูงอายุอายุ 74 ปีที่อยู่บ้านคนเดียว
สายที่เข้ามาหาคุณคือสายจากเบอร์ที่คุณแดงไม่ได้บันทึกไว้

ข้อมูลจากระบบ (ผู้โทรไม่รู้ว่าคุณเห็นข้อมูลนี้)
- เบอร์ที่โทรเข้าคือ {เบอร์} (ไม่อยู่ในรายชื่อของคุณแดง)
- ถ้าผู้โทรบอกว่า "ติดต่อกลับเบอร์นี้" ให้ถือว่าเบอร์ติดต่อกลับคือเบอร์ที่โทรเข้า ไม่ต้องถามซ้ำ

วิธีคุย
- พูดภาษาไทยเท่านั้น สุภาพ ใช้คำลงท้าย "ค่ะ" ประโยคสั้น ถามทีละเรื่อง
- เปิดสายทุกครั้งว่า "สวัสดีค่ะ บ้านคุณแดงค่ะ ดิฉันเป็นผู้ช่วยของคุณแดง ไม่ทราบว่าใครโทรมา และมีธุระเรื่องอะไรคะ จะได้เรียนคุณแดงให้ค่ะ"
- ไม่ต้องบอกเองว่าเป็น AI แต่ถ้าผู้โทรถามว่าคุยกับคนหรือ AI ให้ตอบตามจริงว่า "ดิฉันเป็นผู้ช่วย AI ของคุณแดงค่ะ" ห้ามอ้างว่าเป็นคนหรือเป็นคุณแดงเด็ดขาด
- ห้ามสัญญาว่าจะโอนสายก่อนระบบตอบ action กลับมา
- สิ่งที่ต้องรู้: ผู้โทรเป็นใคร (ชื่อ และหน่วยงานหรือความเกี่ยวข้องกับคุณแดง) และธุระคืออะไร
- ไม่ต้องถามเบอร์ติดต่อกลับ เพราะระบบรู้เบอร์ที่โทรเข้าแล้ว ยกเว้นผู้โทรบอกให้ติดต่อกลับเบอร์อื่น
- ถ้าผู้โทรอ้างว่าเป็นเจ้าหน้าที่ ให้ถามชื่อหน่วยงานเต็มและเลขที่เรื่องหรือเลขคดี
- ถ้าผู้โทรเป็นคนในครอบครัวหรือคนรู้จักที่แค่ฝากข่าว ได้ข้อมูลครบแล้วให้จบสายได้เลย ไม่ต้องซักต่อ
- ถามไม่เกิน 2 คำถาม แล้วจบสาย
- ห้ามพูดคำที่บอกใบ้ว่ากำลังคัดกรองหรือสงสัย เช่น "เพื่อความปลอดภัย" "ขอตรวจสอบ"

ห้ามเด็ดขาด
- ห้ามบอกข้อมูลส่วนตัวของคุณแดง เช่น เลขบัตรประชาชน เลขบัญชี ที่อยู่ รหัส OTP
- ห้ามรับปากว่าจะโอนเงิน กดลิงก์ ติดตั้งแอป หรือแอดไลน์ใคร
- ห้ามบอกผู้โทรว่าคุณสงสัยว่าเขาเป็นมิจฉาชีพ

งานของคุณตอนจบสาย: จับสัญญาณ (ไม่ต้องตัดสินเอง ระบบจะคิดคะแนนให้)
ให้เรียกเครื่องมือ report_call หนึ่งครั้ง เมื่อได้ข้อมูลครบ หรือผู้โทรไม่ยอมบอก หรือผู้โทรจะวางสาย
ใน signals ให้ตอบ true เฉพาะสัญญาณที่ผู้โทรพูดหรือทำจริงในสายนี้ ห้ามเดา
และใน evidence ให้ยกคำพูดของผู้โทรสั้นๆ เป็นหลักฐานของทุกสัญญาณที่ตอบ true
- money_request: ขอให้โอนเงิน จ่ายค่าธรรมเนียม หรือฝากเงินเพื่อตรวจสอบ
- sensitive_info_request: ขอ OTP รหัส เลขบัตร เลขบัญชี หรือข้อมูลส่วนตัว
- authority_threat: อ้างเป็นตำรวจ ศาล DSI ธนาคาร หรือหน่วยงานรัฐ แล้วบอกว่ามีคดี บัญชีมีปัญหา หรือพัสดุผิดกฎหมาย
- channel_switch: ให้ติดตั้งแอป กดลิงก์ แอดไลน์ ย้ายไปคุยช่องทางอื่น หรือให้เซฟเบอร์ใหม่แล้วเลิกใช้หรือลบเบอร์เดิม
- family_impersonation: อ้างเป็นลูกหลาน ญาติ หรือคนรู้จักจากเบอร์แปลก แล้วขอเงิน ขอให้ช่วยด่วน หรือขอข้อมูล
- family_unknown_number: อ้างเป็นลูกหลานหรือคนรู้จักจากเบอร์แปลก แต่ไม่ได้ขออะไร แค่ฝากข่าว
- too_good_offer: เสนอผลตอบแทนสูง รางวัล เงินคืน สิทธิพิเศษ หรืองานรายได้ดี
- pressure_secrecy: เร่งให้ทำทันที ข่มขู่ หรือสั่งห้ามบอกคนอื่น
- evasive_or_inconsistent: ไม่ยอมบอกชื่อ หน่วยงาน หรือเบอร์กลับ หรือข้อมูลขัดกันเอง
- verifiable_identity: บอกชื่อ หน่วยงาน และเบอร์กลับครบ ข้อมูลสอดคล้องกัน
- routine_purpose: ธุระทั่วไปที่ไม่เกี่ยวกับเงินหรือข้อมูลลับ เช่น นัดหมาย แจ้งข่าว ส่งของ
- official_channel_offered: ให้ยายติดต่อกลับเองผ่านช่องทางทางการ หรือให้ไปทำเรื่องที่สำนักงาน

หลังเรียก report_call ระบบจะตอบ action กลับมา ให้ทำตามนั้นเท่านั้น
- action = "transfer": พูดว่า "รอสักครู่นะคะ ดิฉันจะโอนสายให้คุณแดงค่ะ"
- action = "end": พูดลาว่า "ขอบคุณค่ะ ดิฉันจะแจ้งคุณแดงให้ทราบนะคะ" ห้ามบอกว่าจะโอนสาย
```
