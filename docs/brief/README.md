# โจทย์จากผู้จัด (สไลด์ Workshop 20 พ.ย. 2569)

ที่มา: สไลด์ Data Echo × Future Trends ในงาน AI Skillwar for Developer × COM7 & AWS (รูปอยู่ในโฟลเดอร์นี้)

## เลือก 1 แนวทาง ใช้ AI แก้ปัญหาเมืองกรุงฯ

| ธีม | หัวข้อย่อยที่สไลด์ยกมา |
|---|---|
| การเดินทางและจราจร | รถติด · ขนส่ง · เส้นทาง · จุดเสี่ยงอุบัติเหตุ |
| การเข้าถึงบริการภาครัฐ | แจ้งปัญหา · ติดตามเรื่องร้องเรียน · ข้อมูลเมือง |
| คุณภาพชีวิตและสิ่งแวดล้อม | ขยะ · คุณภาพอากาศ · ธุรกิจรายย่อย |

## ข้อบังคับผลงาน: สร้างระบบที่รันได้จริง

1. พัฒนาเป็น Web / Mobile / Desktop
2. Core Flow ตอบโจทย์ที่เลือก
3. AI อย่างน้อย 1 ฟีเจอร์ เชื่อมกับระบบหลัก
4. ใช้ AI/API เป็นแกนสำคัญ
5. Demo ตั้งแต่ Input ถึงผลลัพธ์
6. แจ้งเมื่อใช้ Mock Data ที่เตรียมไว้

## ยังต้องถามผู้จัด

- หัวข้อย่อยข้างบนเป็นตัวอย่าง หรือต้องอยู่ในนั้นเท่านั้น (ไอเดียผู้สูงอายุไม่อยู่ในหัวข้อย่อยตรงๆ)
